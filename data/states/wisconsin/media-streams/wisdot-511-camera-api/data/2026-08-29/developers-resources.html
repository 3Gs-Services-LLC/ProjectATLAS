511WI Data Feed

The 511WI data feeds contain real-time traffic and transit event information provided by the Wisconsin Department of Transportation (WisDOT).

It is a single point of access for all publically available 511WI information including all current:

  • Incidents/accidents,
  • Construction projects,
  • Special events and
  • Camera images in Wisconsin.

The feed is updated as individual events become active or updated. Events are also removed from the feed as they expire.

The data feed is accessed through a web connection and is available in XML format.

  • If you did not create a My 511WI account on this site, then follow step 1, otherwise, skip to step 3.

    1. Sign up for a My 511WI account to access the 511WI Data Feed
    2. Confirm your registration by clicking on the link in the confirmation email you should receive after signing up for a My 511WI account
    3. Login to the website
    4. Go to the 511WI Data Feed Documentation, under the Developer API Key section, submit the reasons for the API Key request.
    5. Once approved, you will receive an email with your Developer API key.
